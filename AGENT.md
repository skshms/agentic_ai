# AGENTS

## Project Guidelines

- Always write tests before completing the code.
- Prefer clarity to cleverness.
- Follow PEP 8.
- Avoid shared mutable state.
- Structure the code using Domain-Driven Design.
- Use the repository pattern for persistence abstraction.
- Use structured logging.
- Use FastAPI.
- Use `pytest` for tests.
- Use type hints.
- Validate concurrency assumptions.
- Keep functions small and composable.
- Run `pytest` after every major change.
- Never suppress exceptions silently.
